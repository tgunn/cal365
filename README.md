# Calisthenics 365 — install as a native app on Android

You'll host these 5 files free on GitHub Pages, then install from Chrome.
Takes ~10 minutes, no coding. Once installed, the app has its own icon,
opens full-screen with no browser bars, and works fully offline.

## Step 1 — Get the files onto GitHub
1. Go to github.com and create a free account (skip if you have one)
2. Tap "+" → "New repository"
3. Name it:  cal365   → set it to Public → Create repository
4. Tap "uploading an existing file" (or Add file → Upload files)
5. Upload ALL 5 files from this zip:
   index.html, manifest.json, sw.js, icon-192.png, icon-512.png
6. Tap "Commit changes"

## Step 2 — Turn on GitHub Pages
1. In your repository, go to Settings → Pages
2. Under "Source" choose: Deploy from a branch
3. Branch: main, folder: / (root) → Save
4. Wait 1–2 minutes, refresh — you'll see your site URL:
   https://YOUR-USERNAME.github.io/cal365/

## Step 3 — Install on your phone
1. Open that URL in Chrome on your Android phone
2. Chrome may show an "Install app" banner — tap it
   (otherwise: ⋮ menu → "Add to Home screen" → Install)
3. Done. Find "Cal365" in your app drawer / home screen

## Notes
- All data (progress, streaks, photos) is stored ONLY on your phone.
  Nothing is uploaded anywhere. Clearing Chrome's site data erases it.
- Photos live in the app's private storage on-device.
- Works with no internet after the first load.
- Want to tweak the program later? Edit index.html, re-upload to
  GitHub, and the app updates itself next time you open it online.
